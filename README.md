# BLINQ v0.2.0

প্রাইভেট মেসেজিং অ্যাপ। সার্ভার শুধু এনক্রিপ্টেড ডেটা বহন করে, পড়তে পারে না।

## চালু করার ধাপ (সবই ফ্রি)
1. GitHub-এ **পাবলিক** repo বানিয়ে এই ফাইলগুলো push করুন।
2. Cloudflare ফ্রি অ্যাকাউন্টে API Token (Edit Cloudflare Workers টেমপ্লেট) ও Account ID নিন। repo → Settings → Secrets → `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`।
3. Actions → **Deploy relay** চালান। Cloudflare ড্যাশবোর্ডে `mess-relay.<আপনার-নাম>.workers.dev` URL পাবেন।
4. repo → Settings → Variables → `RELAY_URL` = সেই `https://...` URL।
5. Actions → **Android APK** চালান → artifact থেকে `app-debug.apk` নামিয়ে ইনস্টল।
6. অ্যাপে "নিজেকে টেস্ট মেসেজ পাঠান" চাপুন। "পেলাম" দেখালে v0.1.0 ঠিক আছে।
7. iOS: Actions → **iOS unsigned IPA** → artifact নামিয়ে Sideloadly দিয়ে ইনস্টল (আপনার আগের পদ্ধতি অনুযায়ী বদলে নিতে পারেন)।

## v0.2.0 নোট
- অ্যাপ আইডি বদলেছে, তাই আগের "Mess" অ্যাপ আলাদা থাকবে। মুছে নতুন BLINQ ইনস্টল করুন।
- ব্যবহার: দুই ফোনে অ্যাপ খুলুন → ➕ → একজন অপরজনের QR স্ক্যান (ক্যামেরা বা গ্যালারি) → মেসেজ।
- এনক্রিপশন লাইব্রেরি: `@privacyresearch/libsignal-protocol-typescript` (লাইসেন্স GPL-3.0, তাই BLINQ-এর কোড পাবলিক রাখুন)।

## জানা সীমা
- এখনো চালিয়ে পরীক্ষা হয়নি। লাইব্রেরির নাম ও API আমার স্মৃতি থেকে লেখা, তাই `npm install` বা বিল্ডে ত্রুটি আসতে পারে। লগ পাঠালে ঠিক করব।
- one-time prekey নেই (শুধু signed prekey)।
- চাবি ও চ্যাট সাধারণ লোকাল স্টোরেজে (PIN ও Keystore v0.4.0-এ)।
- রিলে দেখতে পায় কে কাকে মেসেজ পাঠাচ্ছে (বিষয়বস্তু নয়)।
- যে কেউ আপনার ID জানলে মেইলবক্সে মেসেজ ফেলতে পারে (সর্বোচ্চ ১০০০টি, ৩০ দিন)।
- নিজের নাম QR-এ ও প্রতিটি মেসেজের ভেতরে (এনক্রিপ্টেড) যায়। দৃশ্যমানতা সুইচ পরে।

## v0.4.0 নোট (সীমা)
- PIN শুধু অ্যাপ খোলার তালা। ফোনের স্টোরেজে ডেটা এখনো PIN দিয়ে এনক্রিপ্ট করা নয়। এটা পরের ধাপের কাজ।
- iOS-এ স্ক্রিনশট আটকানো যায় না। শুধু অ্যাপ-সুইচারে স্ক্রিন ঢাকা হয় (নিশ্চিত নয়)।
- নোটিফিকেশন এখনো নেই, তাই "নোটিফিকেশনে মেসেজ লুকানো" ও মিউটের আসল কাজ বাকি।
- ডিজঅ্যাপিয়ারিং ও সবার জন্য ডিলিট নির্ভর করে অপর পক্ষের অ্যাপের ওপর।
- বায়োমেট্রিক প্লাগইন (`@aparajita/capacitor-biometric-auth ^8`) আমার স্মৃতি থেকে বাছা। `npm install` ব্যর্থ হলে লগ পাঠান।

## v0.5.0 নোট
- ডেটা এনক্রিপশন (PIN দিয়ে) এই সংস্করণে নেই। বায়োমেট্রিক চালু থাকলে সেই চাবি রাখতে ফোনের Keystore/Keychain প্লাগইন লাগবে, তাই আলাদা ধাপে হবে।
- আইকন তৈরির ধাপ (`@capacitor/assets`) আমি চালিয়ে দেখিনি। ব্যর্থ হলে লগ পাঠান।
- ক্যামেরা স্ক্যান নিয়ে কোড বদলানো হয়নি (আপনার ফোনের ক্যামেরা সমস্যার কারণে পরীক্ষা হয়নি)।
